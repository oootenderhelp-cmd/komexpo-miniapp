# Komexpo Work — Архитектура платформы

## Обзор

Komexpo Work — фриланс-платформа, аналог Kwork.ru, с расширенными ролями пользователей, безопасной сделкой (эскроу), рекламным кабинетом и дашбордом владельца. Платформа позволяет заказчикам находить исполнителей через каталог услуг (кворки) и биржу проектов.

## Технологический стек

| Компонент | Технология |
|-----------|-----------|
| Frontend | React 19 + TypeScript + Tailwind CSS 4 |
| Backend | Express 4 + tRPC 11 |
| База данных | MySQL (TiDB) через Drizzle ORM |
| Аутентификация | Manus OAuth + JWT сессии |
| Файловое хранилище | S3-совместимое хранилище |
| Сборка | Vite 7 |
| Тестирование | Vitest |
| Маршрутизация | Wouter (клиент) |

## Роли пользователей

| Роль | Описание | Доступ |
|------|----------|--------|
| user | Обычный пользователь (заказчик/подрядчик) | Каталог, биржа, личный кабинет |
| admin | Администратор | + Модерация, управление пользователями |
| owner | Владелец платформы | + Полная статистика, управление доступами |

Внутри роли `user` пользователь может быть одновременно заказчиком и подрядчиком (переключение через профиль).

### Статусы подрядчиков

- **Фрилансер** (`freelancer`) — независимый исполнитель
- **Подрядчик/Агентство Komexpo** (`agency`) — верифицированное агентство
- **Сотрудник Komexpo** (`employee`) — штатный сотрудник платформы

## Безопасная сделка (Эскроу)

### Процесс

1. Заказчик создаёт заказ → средства резервируются на балансе платформы
2. Подрядчик выполняет работу → отмечает как "Доставлено"
3. Заказчик принимает работу → средства переводятся подрядчику
4. При споре → арбитраж администратором

### Комиссия

- Фиксированная ставка: **20%**
- Формула: `commission = amount × 0.20`
- Подрядчик получает: `contractorPayout = amount - commission`

### Статусы заказа

```
pending → in_progress → delivered → completed
                     ↓              ↓
                  revision       dispute → resolved
                     ↓
                  cancelled
```

## API (tRPC Роутеры)

### Публичные процедуры

- `categories.list` — список категорий
- `kvorki.list` — каталог услуг с фильтрами
- `kvorki.getById` — детали кворки
- `projects.list` — биржа проектов
- `projects.getById` — детали проекта
- `projects.responses` — отклики на проект

### Защищённые процедуры (требуют авторизации)

- `profile.me / update` — управление профилем
- `kvorki.create / my` — создание и управление кворками
- `projects.create / respond` — создание проектов и откликов
- `orders.*` — управление заказами
- `transactions.*` — финансовые операции
- `reviews.create` — оставить отзыв
- `chat.*` — обмен сообщениями
- `favorites.*` — избранное
- `notifications.*` — уведомления
- `ads.*` — рекламный кабинет

### Административные процедуры

- `admin.users / kvorki / disputes` — просмотр данных
- `admin.updateUserRole` — изменение роли
- `admin.moderateKvorka` — модерация услуг
- `admin.resolveDispute` — разрешение споров

### Процедуры владельца

- `owner.stats` — полная статистика платформы
- `owner.allUsers` — все пользователи
- `owner.setRole` — назначение ролей

## Финансовая система

### Типы транзакций

| Тип | Описание |
|-----|----------|
| `deposit` | Пополнение баланса |
| `withdrawal` | Вывод средств |
| `escrow_hold` | Резервирование при заказе |
| `escrow_release` | Выплата подрядчику |
| `commission` | Комиссия платформы |
| `refund` | Возврат средств |

### Статусы транзакций

- `pending` — ожидает обработки
- `completed` — завершена
- `failed` — ошибка
- `cancelled` — отменена

## Рекламный кабинет

Пользователи могут создавать рекламные кампании с указанием:
- Заголовок и баннер (URL изображения)
- URL перехода
- Место размещения: `catalog`, `projects`, `sidebar`, `main`
- Бюджет (цена за день)
- Даты начала и окончания

Статистика: показы (impressions) и клики (clicks).

## Деплой

Платформа готова к деплою на сервер Beget или любой Node.js хостинг:

```bash
# Сборка
pnpm build

# Запуск production
NODE_ENV=production node dist/index.js
```

### Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `DATABASE_URL` | Строка подключения к MySQL |
| `JWT_SECRET` | Секрет для подписи JWT |
| `VITE_APP_ID` | ID приложения OAuth |
| `OAUTH_SERVER_URL` | URL сервера OAuth |
| `PORT` | Порт сервера (по умолчанию 3000) |
