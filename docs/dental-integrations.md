# Откуда берутся заявки

Платформа сама заявок не создаёт — она их принимает, оценивает, распределяет по
клиникам и следит за сроками. Этот документ отвечает на вопрос «откуда они
падают» и «почему человек вообще оставит отклик».

## Пять входов

| Вход                        | Кто присылает                         | Что нужно настроить                     |
| --------------------------- | ------------------------------------- | --------------------------------------- |
| Своя форма записи `/dental` | Люди с рекламы и из поиска            | Ничего, работает сразу                  |
| Виджет на чужом сайте       | Сайты клиник-партнёров, свои лендинги | Вставить один тег `<script>`            |
| Вебхук формы                | Тильда, Яндекс Формы, лид-формы ВК    | Указать адрес и ключ в настройках формы |
| Колл-трекинг                | Входящие звонки                       | Настроить вебхук в телефонии            |
| Прямая интеграция           | Любая своя или чужая система          | POST с JSON                             |

Все входы, кроме своей формы, идут через один адрес и различаются ключом
источника. Ключ выпускается в кабинете на вкладке «Источники», показывается
один раз — в базе лежит только его хеш.

## Общий вход

```
POST /api/lead-intake
X-Api-Key: dlk_<префикс>_<секрет>
Content-Type: application/json

{
  "name": "Анна",
  "phone": "+7 900 111-22-33",
  "city": "Казань",
  "service": "implantaciya",
  "comment": "Нет двух зубов",
  "consentPd": true,
  "consentMarketing": true,
  "utm_source": "yandex",
  "utm_campaign": "kzn_implant"
}
```

Ответ:

```json
{
  "ok": true,
  "publicId": "DL-7K2M9XQA",
  "urgency": "medium",
  "clinic": "Дентал-Про"
}
```

Что важно знать про этот вход:

- **Названия полей распознаются сами.** Тильда шлёт `Name` и `Phone`, лид-форма
  ВК кладёт ответы в массив, Яндекс Форма — во вложенный объект. Разбор для
  каждого типа вынесен в отдельную функцию и покрыт тестами, поэтому новый
  источник подключается правкой одного списка, а не отладкой на живом трафике.
- **Повторная доставка не создаёт дубль.** Внешние системы любят слать вебхук
  дважды; если источник передал свой `id`, второй запрос вернёт тот же номер
  заявки.
- **Согласие обязательно.** Заявка без подтверждённого согласия на обработку
  данных не принимается — вернётся ошибка. Исключение одно: входящий звонок,
  человек сам набрал номер, это и есть обращение.
- **Домен можно ограничить.** У источника указывается домен, и заявки с чужих
  сайтов по этому ключу не пройдут.
- **Ограничение частоты** — 120 заявок в минуту на ключ. Вход открыт в
  интернет, без этого его быстро зальют.

## Виджет для сайта

```html
<script
  src="https://ваш-домен/api/lead-widget.js"
  data-key="dlk_xxxxxxxx_..."
  data-city="Казань"
  data-title="Записаться к стоматологу"
></script>
```

Появляется кнопка внизу справа, по клику — форма с именем, телефоном, городом,
жалобой и двумя галочками согласия. Работает на любом сайте, ничего больше
подключать не нужно.

## Почему человек оставит заявку

Форма сама по себе не приносит заявок. Работают четыре вещи, и все они уже
заложены в модуль:

1. **Лид-магнит на каждое направление.** Не «оставьте заявку», а «осмотр и
   снимок в день обращения бесплатно», «бесплатный подбор системы импланта и
   расчёт стоимости». Список зашит в каталог услуг и виден на форме.
2. **Скорость ответа.** Человеку с острой болью обещано 15 минут, и это
   отдельно контролируется. Кто отвечает первым, тот и получает пациента — в
   стоматологии это решает больше, чем цена.
3. **Короткая форма.** Имя, телефон, город, что беспокоит. Всё остальное
   администратор спросит в разговоре.
4. **Живой трафик.** Без рекламы форму никто не увидит. Семантика по всем
   направлениям и структура кампаний — в `docs/dental-traffic.md`.

## Чего в модуле нет и не будет

Сбора контактов из соцсетей, чатов, пабликов, с чужих сайтов и из чужих
рекламных кабинетов. Жалоба на зубную боль — сведения о здоровье, особая
категория персональных данных. Клиника, которая купит такой лид, отвечает
вместе с поставщиком, поэтому первый же вопрос покупателя — откуда контакт.

Это не только про закон: лид без согласия конвертируется в разы хуже. Человек,
который сам оставил заявку и ждёт звонка, и человек, которому позвонили после
поста в чате — это два разных разговора.
