# PRIVACY & LEGAL NOTES — tendrovik-competitor-intelligence

## Юридический статус

Данный модуль предоставляет **информационную рекомендацию** для принятия решений
человеком. Он **не является**:

- юридическим заключением или правовой консультацией
- основанием для автоматической подачи заявок
- заменой проверки документов, лицензий и аккредитации
- гарантией победы или допуска к участию в тендере

Все юридически значимые действия (подача заявок, подписание документов,
выставление цены) **требуют ручного подтверждения** человеком.

## Персональные данные

| Тип данных | Обработка | Примечание |
|-----------|-----------|------------|
| ИНН юрлица | Идентификатор | Публичная информация |
| ОГРН | Идентификатор | Публичная информация |
| Наименование юрлица | Отображение | Публичная информация |
| Финансовые показатели | Расчёт скоринга | Из открытых отчётов (РСБУ) |
| ФИО ИП (если есть) | Отображение | ПД — требуется согласие |
| Контактные данные | **Не хранятся** | Модуль не работает с контактами |

### ФИО индивидуальных предпринимателей

Если данные содержат ФИО ИП, это персональные данные по 152-ФЗ.
Перед загрузкой таких данных убедитесь:

1. Данные получены из открытых источников (ЕГРИП) или с согласия субъекта
2. Обработка соответствует заявленной цели (анализ конкурентной среды)
3. Данные не передаются третьим лицам без основания

## Источники данных

Модуль принимает данные **только** из ручного импорта пользователем.

### Разрешённые источники
- CSV/JSON экспорт из открытых реестров (ЕИС, ЕГРЮЛ, ЕГРИП)
- Сохранённый пользователем PDF/снимок профиля компании
- Ручной ввод данных пользователем
- Структурированный экспорт из учётных систем пользователя

### Запрещённые методы получения данных
- Автоматический парсинг/скрейпинг сайтов (Rusprofile, ЕИС и др.)
- Браузерная автоматизация (Puppeteer, Playwright, Selenium)
- Использование API без авторизации или с нарушением ToS
- Использование чужих API-ключей или учётных данных
- Обход robots.txt, CAPTCHA, rate limits
- Покупка баз данных из неавторизованных источников

## Rusprofile

`RusprofileImportAdapter` предназначен **только** для импорта данных,
которые пользователь **самостоятельно и легально** получил:

- Сохранённый HTML/PDF страницы (вручную, не автоматизированно)
- Экспортированный CSV/Excel отчёт через легальный API (с договором)
- Данные, введённые вручную по результатам визуального ознакомления

Модуль **не делает** HTTP-запросов к rusprofile.ru и не содержит URL или endpoint
этого сервиса.

## GDPR / 152-ФЗ

| Требование | Статус |
|-----------|--------|
| Минимизация данных | Только необходимые для скоринга поля |
| Ограничение цели | Анализ конкурентной среды для тендера |
| Точность данных | `DataFreshness` + `staleAfterDays` на каждом факте |
| Право на удаление | `adapter.clear()` удаляет все загруженные данные |
| Передача третьим лицам | Модуль не передаёт данные за пределы процесса |
| Шифрование | На ответственности инфраструктуры (HTTPS, шифрование at rest) |
