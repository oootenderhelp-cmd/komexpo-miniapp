# tendrovik-source-adapters

Переносимый модуль нормализации публичных тендерных источников для платформы
«Тендровик AI». Содержит интерфейсы, реестр 15 площадок, gate-механизм
блокировки импорта и нормализатор демонстрационных фикстур.

## Безопасность

- **Никаких сетевых вызовов.** Модуль не делает HTTP-запросов, не скрейпит
  сайты, не загружает файлы.
- **Импорт заблокирован по умолчанию.** Каждый источник в реестре имеет
  `gate: CLOSED_GATE`. Импорт разрешается только после явной верификации
  всех 4 условий gate.
- **Нет логинов, ключей, CAPTCHA, подачи заявок.**
- **Нет регистрации на площадках.**
